## 2. About the Project

Modern fintech environments are complex ecosystems containing several interconnected components that operate under strict requirements such as data privacy, high availability and resiliency. This project
is a *Proof-of-Concept (PoC) Microservices Architecture* designed to simulate a real-world Fintech backend.

It implements *Domain-Drive Design (DDD)* using a monorepo structure. Its core advantage is the ease
with which different cloud native design patterns can be implemented and benchmarked. Patterns such as:

- *Edge Routing* & *BFF*     : Spring Cloud Gateway
- *Security & SPII Isolation*: HashiCorp Vault
- *Asynchronous Choreography*: event-driven message exchange between Payment and Notification service
- *Observavility*            : Prometheus/Grafana

Tech Stack: Java 26, Spring Boot 3.x, Docker, PostgreSQL, Apache Kafka, HashiCorp Vault.
